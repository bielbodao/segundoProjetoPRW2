# ReelVault

Catálogo de filmes para consultar, cadastrar, alterar e remover títulos usando uma API mockada.

## Tecnologias

- React
- Vite
- React Router DOM
- Axios

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run lint
npm run build
```

## API

O aplicativo utiliza `https://6ade805e4e88f1bba4a52902.mockapi.io/filmes`.

## Publicação

O arquivo `vercel.json` configura o fallback para `index.html`, permitindo acessar diretamente as rotas do aplicativo.
